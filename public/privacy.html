🏮 象棋占卜 隱私權政策

最後更新日期：2026-08-02

1. 資料收集

象棋占卜不收集、不傳輸、不分享任何個人資料。

  • 所有占卜記錄、收藏、設定皆儲存在您的本機裝置內（經由 AsyncStorage / IndexedDB），不會上傳到任何伺服器。
  • 本 App 無帳號系統、無第三方登入。

2. 資料使用

您在本 App 內產生的所有資料（占卜歷史、收藏資料夾、個人設定）僅用於提供占卜服務本身，包括：

  • 歷史記錄查閱與統計圖表
  • 收藏管理與資料夾分類
  • 主題、語言、音效等個人偏好記憶

這些資料永不離開您的裝置，除非您主動使用「雲端同步」功能（該功能需自建後端伺服器，預設為關閉狀態）。

3. 通知權限

本 App 提供可選的「每日占卜提醒」功能。若您啟用此功能，App 會請求通知權限，並在每日上午 9:00 發送一條本地排程通知。

  • 通知完全由裝置本地排程，不經過任何遠端伺服器。
  • 您可隨時在設定頁面關閉此功能。

4. 第三方服務

  • AI 深度解讀：若您設定了 DeepSeek API 金鑰，占卜結果會傳送至 DeepSeek API 進行解讀。金鑰儲存在您的伺服器端環境變數中，不會進入前端程式碼。
  • 雲端同步：此功能需要您自行部署後端伺服器並設定端點 URL。資料傳輸僅發生在您與您自己的伺服器之間。
  • 本 App 不含廣告 SDK、不含分析追蹤、不含第三方登入。

5. 兒童隱私

本 App 不收集任何個人資料，適用於所有年齡層使用者。

6. 您的權利

由於所有資料儲存在您的本機裝置上，您可以：

  • 在設定中「清除所有歷史」以刪除占卜記錄
  • 使用「備份資料」匯出 JSON 檔案
  • 刪除 App 即完全清除所有本機資料

7. 政策更新

若隱私權政策有重大變更，將在 App 更新說明中告知。建議定期查閱此頁面。

繼續使用本 App 即表示您同意本隱私權政策。
